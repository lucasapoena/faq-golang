# Fase 1 — Fundamentos

Objetivo: Aprender a sintaxe básica do Go e entender os conceitos principais.

## 📖 Conteúdo

* [x] [Instalação do Go e configuração de ambiente](./instalacao.md)
* [x] Primeiro programa: [hello.go](./exemplos/hello.go) (`package main`, `func main`, `fmt.Println`) 
* [ ] Variáveis (`var`, `:=`) e constantes (`const`)
* [ ] Tipos básicos: `int`, `float`, `string`, `bool`
* [ ] Arrays, slices e maps
* [ ] Estruturas de controle: `if`, `else`, `switch`
* [ ] Laços: `for`, `range`
* [ ] Funções (parâmetros, retorno múltiplo, funções anônimas, closures)
* [ ] Structs e métodos
* [ ] Ponteiros (`*`, `&`)
* [ ] Interfaces e polimorfismo em Go
* [ ] Módulos (`go mod init`, `go mod tidy`)

## Como usar
1. Siga **instalação e configuração** para preparar seu ambiente.
2. Leia **tipos e variáveis** e rode os códigos em `./exemplos`.
3. Resolva os **exercícios** e marque seu progresso.
